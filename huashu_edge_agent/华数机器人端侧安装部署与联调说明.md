# 华数Ⅲ型工业机器人 — 端侧采集客户端安装与现场接入实战指南 (v2.5)

> **适用标准**：华数机器人《V1.6.11_SocketCmd 网络通讯功能使用说明书_A0》  
> **适用对象**：现场自动化工程师、机器人二次开发人员、交付实施工程师  
> **适用环境**：华数机载工控机 (Windows 7/10/11 / Linux Ubuntu) 或现场局域网边缘网关

## 一、系统架构与端侧角色定位

在工厂现场，华数机器人控制柜处于**工厂内网隔离专网**环境（如 `127.0.0.1` 或 `10.10.56.214`，端口默认 `23333` / `23234`），外部中心服务器无法主动发起对机器人的入站连接。

```
+-------------------------------------------------------------+
| 工厂现场 (局域网内网环境)                                   |
|                                                             |
|  [华数Ⅲ型控制柜]                                           |
|       │                                                     |
|       │ (本地 TCP:23333 SocketCmd 协议)                     |
|       ▼                                                     |
|  [机载工控机 / 现场网关]                                    |
|   └── huashu_edge_agent (本采集客户端)                      |
+───────────────────────────┬─────────────────────────────────+
                            │ 
                            │ 主动发起广域网 MQTT 上行长连接
                            │ (公网 IP: 106.55.248.254:1883)
                            ▼
+─────────────────────────────────────────────────────────────+
| 云端中心 / 穿透中枢 (106.55.248.254)                        |
|   ├── MQTT Broker (Port 1883)                               |
|   └── Web 工业物联网管理大屏 (Port 8000)                    |
+-------------------------------------------------------------+
```

**本端侧程序的核心使命**：
1. **就地真实采集**：直连华数控制器，毫秒级读取真实 **J1~J6 关节角度**、**笛卡尔 XYZABC 坐标**、**各轴反馈电流矩阵**、**电机使能状态**、**急停状态**与**错误报警码**。
2. **主动向公网推流**：跨越 NAT 与企业防火墙，向中心 MQTT 服务器推送遥测数据，实时点亮大屏。
3. **远程双向控制**：实时监听云端大屏下发的一键使能、复位、急停、工单启动、暂停、全局调速指令，翻译为底层 SocketCmd 命令就地执行。
4. **工业级自愈**：控制器掉电或网线拔掉后秒级感知并标记离线；控制器上电或网络恢复后 1 秒内自动重连。

## 二、部署与使用流程（极简 3 步）

### 步骤 1：将 `huashu_edge_agent` 文件夹复制到机器人工控机
整个文件夹体积小巧（无需大型环境），可直接放在机载工控机桌面。

### 步骤 2：核对与修改配置文件 `edge_config.json`
用文本编辑器打开 `edge_config.json`：

```json
{
  "mqtt": {
    "host": "106.55.248.254",          // 中心云服务器的公网 IP 或域名
    "port": 1883,                      // MQTT 通信端口
    "username": "device_huashu_arm",   // 预设安全认证账号
    "password": "Arm_Secure_2026!",    // 预设安全认证密码
    "topic_state": "robot/huashu_arm/{device_id}/state",
    "topic_sensor": "robot/huashu_arm/{device_id}/sensor",
    "topic_cmd_sub": "cmd/huashu_arm/{device_id}",
    "qos": 1
  },
  "robots": [
    {
      "device_id": "arm_001",          // 机器人设备唯一标识（大屏显示的设备ID）
      "device_name": "华数BR610六轴工业机械臂",
      "ip": "127.0.0.1",               // 控制器 IP (如果是本机工控机填 127.0.0.1)
      "port": 23333,                   // 华数官方 SocketCmd 通信端口 (默认 23333)
      "group_id": 0,                   // 轴组号 (默认 0)
      "axis_count": 6                  // 轴数
    }
  ],
  "collection": {
    "interval_sec": 1.0,               // 遥测采集频率 (建议 1.0 秒)
    "include_io": true
  }
}
```

> 💡 **单机多臂支持**：若一台工控机托管多台机械臂，只需在 `"robots": [...]` 中追加设备配置即可（如 `arm_002`，`ip: "10.10.56.215"`），程序会自动启动多线程并发采集。

### 步骤 3：一键启动

- **Windows 系统**：双击运行 `run_edge_agent.bat`
- **Linux 系统**：在终端执行 `./run_edge_agent.sh`

启动后控制台将输出如下绿灯信息：

## 三、官方控制指令映射一览表

本客户端严格按照华数官方协议标准，支持云端双向远程指令控制：

| 云端指令 (`command`) | 示例参数 (`params`) | 华数控制器底层调用 | 说明 |
|---|---|---|---|
| `start_cycle` / `start` | `{"program": "MAIN.PRG", "speed": 80}` | `mot.setVord(80)` + `vm.start("MAIN.PRG")` | 设定速度并启动生产工序 |
| `stop` | `{"reason": "emergency"}` | `mot.setEstop(true)` + `vm.stop("")` | 紧急停机与程序停止 |
| `reset` / `clear_error` | `{}` | `sys.clearError()` + `sys.reset()` + `mot.setEstop(false)` | 复位伺服并清除系统故障告警 |
| `pause` | `{}` | `vm.pause("")` | 暂停当前工序 |
| `enable` | `{}` | `mot.setGpEn(0, true)` | 伺服电机上使能 |
| `disable` | `{}` | `mot.setGpEn(0, false)` | 伺服电机去使能 |
| `set_speed` | `{"speed": 60}` | `mot.setVord(60)` | 动态调整全局运行速度倍率 (1-100%) |
| `set_do` | `{"port": 1, "value": 1}` | `io.setDOut(1, true)` | 控制数字量输出 (气爪/电磁阀) |
| `jog` | `{"axis": 0, "direction": "+"}` | `mot.startJog(0, 0, 0)` | 单轴连续点动 |
| `stop_jog` | `{}` | `mot.stopJog(0)` | 停止轴点动 |

## 四、现场常见排障问答 (FAQ)

### Q1：启动提示 `无法连接华数控制器 (127.0.0.1:23333)`？
1. 请确认华数控制柜是否已开机上电。
2. 确认华数示教器或上位机软件中，**“网络通讯功能 / SocketCmd”** 开关是否处于开启状态。
3. 若工控机与控制柜之间通过独立网线相连，请确认网卡 IP 与控制柜处于同一网段（例如 `10.10.56.xxx`），并在 `edge_config.json` 中将 `ip` 改为控制柜的实际 IP（如 `10.10.56.214`）。

### Q2：启动提示 `暂无法连接云端 MQTT (106.55.248.254:1883)`？
1. 检查现场工控机是否能正常访问外网（可使用 `ping 106.55.248.254` 检查网络畅通度）。
2. 检查云端安全组/防火墙是否已放行 `1883` 端口。

### Q3：机械臂断电或发生故障时，大屏如何显示？
1. 本程序具备控制器掉电秒级感知与 MQTT 遗嘱消息机制，一旦断电，大屏将在秒级内呈现“离线”状态，绝不会产生虚假死循环数据。
2. 一旦控制柜上电恢复，程序将在 1 秒内自动重连并恢复遥测推流。
