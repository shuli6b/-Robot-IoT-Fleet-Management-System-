# 华数Ⅲ型工业机器人 — 端侧采集客户端安装与现场接入说明

> **适用对象**：现场自动化工程师、机器人二次开发人员、交付实施工程师  
> **适用环境**：华数机载工控机 (Windows 7/10/11 / Linux Ubuntu) 或现场同一局域网下的边缘网关工控机  
> **版本**：v2.0 (现场生产端侧版)

---

## 一、为什么要在机器人端侧安装此程序？

现场工业机器人的控制器通常运行在**工厂内网/隔离专网**环境（如 IP: `10.10.56.214` 或 `127.0.0.1`），无独立公网 IP，外部服务器无法穿透内网主动连接机器人。

**本端侧程序的核心使命**：
1. **就地直连控制器**：在现场同一局域网或本机通过 TCP `23234` 端口连接华数底层控制器，以 1000ms 频率毫秒级采集真实 J1~J6 关节角度、XYZABC 笛卡尔坐标、伺服状态与报警代码。
2. **主动向公网推流**：作为 MQTT 客户端，**主动跨越公网**向中心云服务器（腾讯云/FRP穿透节点）的 MQTT Broker 发送数据，实现全自动跨省/跨网通信。
3. **远程双向控制**：实时监听云端下发的急停、复位、使能、启动工序等控制指令，就地翻译并执行。

## 二、部署与使用流程（极简 3 步）

### 步骤 1：复制本文件夹到机器人机载工控机上
将 `huashu_edge_agent` 文件夹拷贝到机器人的工控机桌面或工控网关中。

### 步骤 2：修改配置文件 `edge_config.json`
用文本编辑器打开 `edge_config.json`：

```json
{
  "mqtt": {
    "host": "123.45.67.89",           // 【重点修改】填入中心云服务器的公网 IP 或穿透域名
    "port": 1883,                      // 【重点修改】填入云端开放的 MQTT 端口
    "username": "device_huashu_arm",   // 系统预设设备认证账号
    "password": "Arm_Secure_2026!",    // 系统预设密码
    "topic_state": "robot/huashu_arm/{device_id}/state",
    "topic_sensor": "robot/huashu_arm/{device_id}/sensor",
    "topic_cmd_sub": "cmd/huashu_arm/{device_id}",
    "qos": 1
  },
  "robots": [
    {
      "device_id": "arm_001",          // 机器人设备唯一标识（大屏显示的设备ID）
      "device_name": "华数BR610六轴工业机械臂",
      "ip": "127.0.0.1",               // 控制器局域网/本机 IP (若是本机填 127.0.0.1)
      "port": 23234,                   // 华数官方 SocketCmd 通信端口
      "group_id": 0,
      "axis_count": 6
    }
  ],
  "collection": {
    "interval_sec": 1.0,               // 遥测采集频率 (建议 1.0 秒)
    "include_io": true
  }
}
```

> 💡 **支持单机托管多台机械臂**：如果一台工控机连接了多台华数机械臂，只需在 `"robots": [...]` 数组中追加 `arm_002`、`arm_003` 等即可，程序会自动启动多线程并发采集。

### 步骤 3：一键启动

- **Windows 系统**：双击运行 `run_edge_agent.bat`
- **Linux 系统**：在终端运行 `./run_edge_agent.sh`

程序启动后会自动完成以下动作：
1. 物理连接本地华数控制器（绿灯握手）。
2. 主动连接云端 MQTT 服务器并注册设备。
3. 高频实时推送真实关节角与坐标。
4. 此时打开云端 Web 管理大屏，即可看到该机械臂瞬间上线并开始舞动！

## 三、控制器常用控制指令说明

本端侧程序原生支持以下云端下发控制指令：

| 指令名称 (`command`) | 示例参数 (`params`) | 华数控制器原生行为 | 说明 |
|---|---|---|---|
| `start_cycle` / `start` | `{"speed": 80, "program": "MAIN_WELD"}` | `sys.start()` | 加载工序并启动生产节拍 |
| `stop` | `{"reason": "manual_stop"}` | `mot.setEstop(1)` | 紧急制动与停机 |
| `reset` | `{}` | `sys.clearError()` + `mot.setEstop(0)` | 复位伺服并清除故障告警 |
| `pause` | `{}` | `sys.pause()` | 暂停当前加工工序 |
| `enable` | `{}` | `mot.setGpEn(0, 1)` | 伺服电机使能上电 |
| `disable` | `{}` | `mot.setGpEn(0, 0)` | 伺服电机去使能断电 |
| `set_speed` | `{"speed": 60}` | `mot.setOverride(60)` | 调整全局运动速度倍率 (0-100) |
| `set_do` | `{"port": 1, "value": 1}` | `usr.setDO(1, 1)` | 控制现场气爪/电磁阀数字量输出 |

## 四、常见问题与现场排障 (FAQ)

1. **提示 `无法连接华数控制器 (127.0.0.1:23234)`**：
   - 请检查华数控制柜是否已上电。
   - 检查示教器/控制系统中是否已开启“二次开发通讯功能 / SocketCmd”服务。
   - 若工控机与控制器通过独立网线相连，请确认工控机网卡 IP 与控制器处于同一网段（例如 `10.10.56.xxx`），并在 `edge_config.json` 中把 `ip` 改为控制器的真实 IP（如 `10.10.56.214`）。

2. **提示 `暂无法连接云端 MQTT`**：
   - 检查现场工控机是否能正常访问外网（可 ping 通公网域名）。
   - 检查云服务器防火墙是否已放行 `1883` 端口。

3. **机械臂断电后大屏如何显示？**
   - 本程序具备掉电感应与遗嘱消息机制，机械臂断电或网线拔掉后，大屏将在秒级内准确呈现“离线/异常”告警，绝不展示虚假死循环数据；上电恢复后 1 秒内自动重连。
