# 昕邦智能装备 · 机器人物联网管控平台 (Robot IoT Fleet Management Platform)

基于 **FastAPI + EMQX (MQTT) + SQLite (WAL模式) + 3D数字孪生** 构建的工业级机器人集群监控、遥测分析与远程指令调度管理系统。

---

## 📋 系统核心功能特点

- **四大品类异构机器人全量接入**：基于 MQTT 工业总线机制，支持华数/协作机械臂、珞石复合 AMR 移动机器人、四足仿生机器狗、空地协同编队 4 大类设备的实时工况与传感器遥测流式上报。
- **全站默认暗色科技风格（Dark Mode Default）**：
  - 登录页与大屏默认采用极简高质感工业深色模式，杜绝白屏闪烁；
  - 界面右上角配备明暗切换按钮（☀️ / 🌙），支持根据使用环境无缝切换，用户偏好自动持久化。
- **动态 CMS 品牌与基地图文管理**：
  - 支持后台可视化自定义平台标题、所属企业、广州番禺运营中心与广州南沙机器人研发中心全部图文与实景图；
  - 地图跳动点（番禺 & 南沙）标签、悬浮卡片及点击弹窗标题与 CMS 全链路 **100% 实时动态联动**。
- **四大品类健康指标与筛选全联动**：
  - 顶部筛选下拉、健康指数卡片（伺服负载、电池健康度、关节扭矩、空地遥感链路）与设备列表标签全品类响应。
- **单台设备工位、名称与任意规格参数（Key-Value）可视化编辑**：
  - 支持管理员在 3D 姿态弹窗中一键增删改任意键值对规格（如额定负载、重复定位精度、防护等级等）。
- **3D 数字孪生姿态控制**：解析六轴机械臂关节角度、空间末端坐标（XYZ）、SLAM 地图坐标，支持仿真联动与下发控制。
- **AI 大模型工业智能诊断**：支持配置通义千问、DeepSeek、OpenAI、Gemini 等 API，提供单设备智能诊断与集群故障排查建议。

## 🌐 界面与服务访问路径（本地与部署默认端口）

| 界面 / 服务 | 访问路径 | 说明 |
| :--- | :--- | :--- |
| **管控大屏主界面** | `http://<服务器IP或127.0.0.1>:8000/` | 默认暗色科技主题，全功能数字孪生管控大屏 |
| **系统登录门户** | `http://<服务器IP或127.0.0.1>:8000/login` | 动态基地地图标记与鉴权登录 |
| **EMQX 物联网控制台** | `http://<服务器IP或127.0.0.1>:18083` | EMQX 5.8 节点监控、客户端连接与 Topic 拓扑 |

## 🚀 快速启动与部署

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
# 启动后台服务
python main.py

# 启动模拟器 (可选)
python mock_robot.py
```
