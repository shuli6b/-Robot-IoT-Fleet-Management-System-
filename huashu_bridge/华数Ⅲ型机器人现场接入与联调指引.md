## 📌 一、通信拓扑与接入原理

华数Ⅲ型机器人控制柜内部运行 HSC3 实时系统，对外开放标准 TCP/UDP Socket 通信接口（默认端口号 **`23234`**）。
现场上位机工控机（Windows 或 Linux）运行本桥接程序（`huashu_adapter.py`），实时读取机械臂位姿、状态与报警，并封装为标准 JSON 报文通过 MQTT 推送至物联网管控平台：

```
┌─────────────────────────────────────────────────────────────┐
│                 华数Ⅲ型机器人控制器 (HSC3 控制柜)             │
│            默认 IP: 10.10.56.214  | 默认端口: 23234          │
└──────────────────────────────┬──────────────────────────────┘
                               │ TCP:23234 (Hsc3 协议)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│       华数-MQTT 边缘采集桥接程序 (huashu_adapter.py)         │
│          运行在现场工控机 IPC 上 (Linux / Windows 通用)       │
└──────────────────────────────┬──────────────────────────────┘
                               │ MQTT 协议 (TCP:1883 / QoS 1)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│          机器人物联网管理平台 (Ubuntu 22.04 LTS)             │
│   EMQX Broker (1883) ──▶ FastAPI 后端 ──▶ Web 大屏实时呈现   │
└─────────────────────────────────────────────────────────────┘
```

## ⚙️ 二、配置文件说明 (`huashu_config.json`)

现场无需修改任何 Python 代码，直接编辑 `huashu_config.json` 即可完成全部配置。当前版本已支持**单节点多设备高并发采集**，可在 `robots` 列表中添加多台机器人。

```json
{
  "robots": [
    {
      "device_id": "arm_001",
      "device_name": "华数BR610六轴工业机械臂_A线",
      "ip": "10.10.56.214",
      "port": 23234,
      "group_id": 0,
      "axis_count": 6
    },
    {
      "device_id": "arm_002",
      "device_name": "华数BR610六轴工业机械臂_B线",
      "ip": "10.10.56.215",
      "port": 23234,
      "group_id": 0,
      "axis_count": 6
    }
  ],
  "robot_common": {
    "timeout_sec": 3.0,
    "reconnect_interval_sec": 5.0
  },
  "mqtt": {
    "host": "127.0.0.1",
    "port": 1883,
    "username": "",
    "password": "",
    "topic_state": "robot/huashu_arm/{device_id}/state",
    "topic_sensor": "robot/huashu_arm/{device_id}/sensor",
    "topic_alarm": "robot/huashu_arm/{device_id}/alarm",
    "topic_cmd_sub": "cmd/huashu_arm/{device_id}",
    "qos": 1
  },
  "collection": {
    "interval_sec": 1.0,
    "include_io": true,
    "enable_alarm_listener": true
  }
}
```

### 重要参数说明：
1. **`robots` 数组**：现场有几台机器人，就在这里填几个字典。确保每台机器人的 `device_id` 和 `ip` 独一无二。
2. **`mqtt.host`**：填入实际的 Ubuntu 云端服务器公网/局域网 IP。如果在本地测试则填 `127.0.0.1`。
3. **`robot_common`**：所有机器人共用的网络超时与重连策略。

| 字段名 | 说明 | 现场推荐设置 |
|---|---|---|
| `robot.ip` | 华数控制器实际 IP 地址 | 现场与机械臂在同一局域网的 IP（如 `192.168.1.100`） |
| `robot.port` | 华数通信端口 | 固定 **`23234`** |
| `mqtt.host` | 物联网管理平台 IP | 部署了本平台的 Ubuntu 服务器 IP（如 `10.31.193.232` 或公网 IP） |
| `mqtt.port` | MQTT 接入端口 | 默认 **`1883`** |
| `collection.interval_sec` | 采集上报周期 | **`1.0`** 秒（可按需调至 0.2~2.0s） |
| `simulation_fallback` | 仿真自愈兜底 | `true`（现场断电或未接控制器时自动产生运动学测试流，不影响大屏联调） |

## 🚀 三、快速启动方法

### 方式 1：Linux 平台启动（工控机为 Ubuntu / Debian）
```bash
cd huashu_bridge
chmod +x *.sh
# 1. 直接按配置文件启动
python3 huashu_adapter.py

# 2. 或通过命令行动态指定 IP 启动（优先于配置文件）：
python3 huashu_adapter.py --robot-ip 192.168.1.100 --mqtt-host 10.31.193.232
```

### 方式 2：Windows 平台启动（工控机为 Windows 10/11）
- 双击运行 **`start_huashu_bridge.bat`**
- 或在 CMD / PowerShell 运行：
  ```powershell
  python huashu_adapter.py --robot-ip 192.168.1.100 --mqtt-host 10.31.193.232
  ```

## 📊 四、上报数据报文规范 (MQTT Payload)

采集器按周期自动分别推送状态与传感器遥测至不同的 Topic。

### 1. 状态报文 (Topic: `robot/huashu_arm/{device_id}/state`)
```json
{
  "timestamp": "2026-08-17 14:00:00",
  "status": "running",
  "error_code": 0,
  "error_msg": "Normal",
  "battery": 100.0,
  "joint_angles": [12.5, 45.2, -88.1, 0.0, 43.1, 120.0],
  "cartesian_pos": {
    "x": 482.35,
    "y": 12.40,
    "z": 395.10,
    "a": 180.00,
    "b": 0.00,
    "c": 12.50
  },
  "emergency_stop": false,
  "enabled": true,
  "mode": "auto"
}
```

### 2. 传感器报文 (Topic: `robot/huashu_arm/{device_id}/sensor`)
```json
{
  "timestamp": "2026-08-17 14:00:00",
  "temperature": 39.5,
  "humidity": 52.1,
  "vibration": 0.024,
  "current": 3.2,
  "voltage": 24.1,
  "motor_temperatures": [42.3, 44.1, 43.8, 41.5, 40.2, 39.8]
}
```

### 3. 下行控制指令 (Topic: `cmd/huashu_arm/{device_id}`)
用于接收云平台下发的控制指令：
```json
{
  "task_id": "tsk_829371",
  "command": "stop",
  "params": {}
}
```

## 🛠️ 五、现场联调与排障速查表

| 现象 | 可能原因 | 解决方法 |
|---|---|---|
| 提示 `无法连接华数控制器 ConnectionRefused` | 1. 机械臂控制柜未上电或网线未插<br>2. IP / 端口错误<br>3. 控制器已达到最大连接数限制 | 1. `ping 控制器IP` 确认物理链路<br>2. 确认端口为 23234<br>3. 重启控制器以释放旧连接 |
| 提示 `MQTT Broker 连接失败` | 1. 物联网平台未启动<br>2. 1883 端口被防火墙拦截 | 1. 确认 Ubuntu 服务器上的 `robot-iot` 与 `emqx` 服务已启动<br>2. 服务器执行 `sudo ufw allow 1883/tcp` |
| Web 大屏未显示机械臂数据 | 1. Topic 不匹配<br>2. device_id 不一致 | 确认 `huashu_config.json` 中的 `device_id` 与大屏添加的 ID 一致（默认 `arm_001`） |
